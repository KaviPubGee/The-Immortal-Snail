# 🐌 The Immortal Snail

A small one-screen 2D survival game about a mouse, an immortal snail, and salt packets that cannot be trusted.

At first, the game seems simple.

Move around.  
Avoid the snail.  
Collect salt.  
Survive.

But after a short boring session...

**the snail starts evolving.**

---

## Game Concept

You control a small mouse/player on a single screen while an immortal snail slowly chases you.

Your goal is to survive for 60 seconds.

Salt packets appear around the screen and can help you by slowing or freezing the snail.

But after the snail evolves, some salt packets become fake.

The fake salt looks almost identical to the real salt, but it has tiny differences. If the player collects fake salt, it triggers a negative effect.

The player has to decide:

**Is this salt worth the risk?**

---

## Controls

| Action | Control |
|---|---|
| Move player | Mouse movement |
| Avoid snail | Move away from it |
| Collect salt | Move over salt packet |
| Restart | Restart button / R key |

---

## Main Gameplay

The game happens on one screen.

The player moves using the mouse.  
The snail follows the player.  
If the snail touches the player, the game is over.

Real salt helps the player.

Fake salt punishes the player.

The longer the player survives, the smarter and more dangerous the snail becomes.

---

## Game Phases

### Phase 1: Simple Survival

The game starts very basic.

- The snail is slow
- Real salt appears
- Salt freezes/slows the snail
- The player learns the basic rules

This phase is meant to feel easy and slightly boring.

Then the game changes.

---

### Phase 2: The Snail Evolves

After a short time, a message appears:

```text
THE SNAIL IS EVOLVING...
```
